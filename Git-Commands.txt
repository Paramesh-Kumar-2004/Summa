GIT COMMANDS & EXPLANATIONS





GitHub Login / Authentication

    `git config --global user.name "Your Name"` – Sets your Git username.
    `git config --global user.email "your-email@example.com"` – Sets your Git email address.
    `git config --global --list` – Checks your Git configuration.
Note: GitHub authentication is usually handled through a browser login using Git Credential Manager or through a Personal Access Token (PAT), rather than a `git login` command.




Git Clone

    `git clone repository_url` – Downloads an existing GitHub repository to your local computer.
    Example: `git clone https://github.com/username/repository.git`
Note: Used when you want to start working on an existing project from GitHub.




Git Status
    git status – Displays the current repository status, including modified, staged, and untracked files.




Git Add
    git add . – Stages all changes in the current directory.
    git add filename – Stages a specific file.  
    git add -A – Stages all new, modified, and deleted files in the repository.





Git Commit
    git commit -m "your commit message" – Saves the staged changes as a commit with a descriptive message.
    git commit -am "your commit message" – Stages and commits modifications to tracked files, but does not include new untracked files.



Git Push
    git push – Uploads local commits to the connected remote repository.
    git push origin branch-name – Pushes local commits to a specific branch on the remote repository.
    git push -u origin branch-name – Pushes the branch to the remote repository and sets its upstream for future pushes.






Git Pull
    git pull – Fetches and integrates changes from the configured remote branch into the current branch.
    git pull origin branch-name – Fetches and integrates changes from a specific remote branch.






Git Branch
    git branch – Lists all local branches.
    git branch branch-name – Creates a new branch.
    git branch -a – Lists all local and remote-tracking branches.
    git branch -d branch-name – Deletes a local branch that has been safely merged.






Git Switch
    git switch branch-name – Switches to an existing branch.
    git switch -c branch-name – Creates a new branch and switches to it.







Git Merge
    git merge branch-name – Merges the specified branch into the current branch.
    git merge --abort – Cancels an in-progress merge when conflicts occur and Git allows the merge to be aborted.






Git Log
    git log – Displays the commit history of the current branch.
    git log --oneline – Displays each commit in a single line.
    git log --oneline --all – Displays commits from all branches in a compact format.





Git Remote
    git remote -v – Displays the remote repository names and their URLs.
    git remote add origin repository-url – Connects the local repository to a remote repository.
    git remote set-url origin repository-url – Changes the URL of the existing remote repository.
    git remote remove origin – Removes the remote connection named origin.







Git Fetch
    git fetch – Downloads new commits and references from the remote repository without merging them into the current branch.
    git fetch origin – Fetches updates from the remote named origin.
    git fetch --all – Fetches updates from all configured remotes.





Git Stash
    git stash – Temporarily saves tracked-file changes and reverts them from the working directory.
    git stash -u – Temporarily saves tracked and untracked file changes.
    git stash list – Lists all saved stashes.
    git stash pop – Applies the latest stash and removes it from the stash list.






Git Reset
    git reset – Unstages staged changes while keeping the file modifications in your working directory.
    git reset filename – Unstages a specific file while keeping its modifications.
    git reset --soft HEAD~1 – Removes the latest commit but keeps its changes staged.
    git reset --hard HEAD~1 – Removes the latest commit and discards its changes from the working directory; use carefully because this can cause data loss.







Git Restore
    git restore filename – Discards unstaged changes in a specific file and restores it to the last committed version.
    git restore . – Discards all unstaged changes in tracked files in the current directory and its subdirectories.
    git restore --staged filename – Unstages a specific file while keeping its changes in the working directory.







Git Config
    git config --global user.name "Your Name" – Sets your Git commit author name for all repositories on your computer.
    git config --global user.email "your-email@example.com" – Sets your Git commit author email for all repositories on your computer.
    git config --global --list – Displays your global Git configuration settings.
    git config user.name – Displays the configured author name for the current repository.
    git config user.email – Displays the configured author email for the current repository.







Git Diff
    git diff – Displays unstaged changes made to tracked files.
    git diff --staged – Displays changes that are staged and ready to commit.
    git diff branch-name – Shows differences between the current branch and the specified branch.
    git diff --stat – Displays a summary of changed files and the number of lines added or deleted.








Git Rebase
    git rebase branch-name – Reapplies the current branch's commits on top of the specified branch.
    git rebase --continue – Continues the rebase after resolving conflicts.
    git rebase --abort – Cancels an in-progress rebase and returns to the original branch state.








Git Cherry-Pick
    git cherry-pick commit-hash – Applies a specific commit from another branch to the current branch.
    git cherry-pick --continue – Continues cherry-picking after resolving conflicts.
    git cherry-pick --abort – Cancels the cherry-pick operation in progress.









Git Tag
    git tag – Lists all tags in the repository.
    git tag tag-name – Creates a lightweight tag for the current commit.
    git tag -a tag-name -m "Release message" – Creates an annotated tag with a message.
    git push origin tag-name – Pushes a specific tag to the remote repository.
    git push origin --tags – Pushes all local tags to the remote repository.
    git tag -d tag-name – Deletes a local tag.







Git Show
    git show – Displays details of the latest commit, including its changes.
    git show commit-hash – Displays details of a specific commit.
    git show --stat – Displays a summary of files changed in the latest commit.






Git Revert
    git revert commit-hash – Creates a new commit that reverses the changes introduced by a specific commit.
    git revert HEAD – Creates a new commit that reverses the latest commit.
    git revert --abort – Cancels an in-progress revert operation.







Git Clean
    git clean -n – Previews untracked files and directories that would be deleted.
    git clean -f – Deletes untracked files from the working directory.
    git clean -fd – Deletes untracked files and directories from the working directory.
    git clean -fdn – Previews untracked files and directories that would be deleted.
    Warning: Git Clean permanently deletes untracked files; preview with `git clean -n` before deleting.








Git Blame
    git blame filename – Shows who last modified each line of a specific file and the corresponding commit.
    git blame -L 10,20 filename – Shows the author and commit details for lines 10 to 20 of a file.









Git Grep
    git grep "search-text" – Searches for specific text in files tracked by Git.
    git grep -n "search-text" – Searches for specific text and displays the matching line numbers.
    git grep -i "search-text" – Searches for text without distinguishing uppercase and lowercase letters.











Git Reflog
    git reflog – Displays the history of recent changes to HEAD and branch references in the local repository.
    git reflog --all – Displays reference history for all local references.
    git reflog show HEAD – Displays recent movements of HEAD, including previous commits and branch switches.
