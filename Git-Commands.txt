GitHub Login / Authentication

    `git config --global user.name "Your Name"` – Sets your Git username.
    `git config --global user.email "your-email@example.com"` – Sets your Git email address.
    `git config --global --list` – Checks your Git configuration.
Note: GitHub authentication is usually handled through a browser login using Git Credential Manager or through a Personal Access Token (PAT), rather than a `git login` command.




Git Clone

    `git clone repository_url` – Downloads an existing GitHub repository to your local computer.
    Example: `git clone https://github.com/username/repository.git`
Note: Used when you want to start working on an existing project from GitHub.




Git Status
    git status – Displays the current repository status, including modified, staged, and untracked files.




Git Add
    git add . – Stages all changes in the current directory.
    git add filename – Stages a specific file.  
    git add -A – Stages all new, modified, and deleted files in the repository.





Git Commit
    git commit -m "your commit message" – Saves the staged changes as a commit with a descriptive message.
    git commit -am "your commit message" – Stages and commits modifications to tracked files, but does not include new untracked files.



Git Push

git push – Uploads local commits to the connected remote repository.

git push origin branch-name – Pushes local commits to a specific branch on the remote repository.

git push -u origin branch-name – Pushes the branch to the remote repository and sets its upstream for future pushes.
